# CODEGUARD — Phase 9 Security Threat Model (Micro-Hardened)

## Retention, Privacy Compliance & Legal Hold Engine

**Document Version:** 1.2.0  
**Methodology:** STRIDE + Multi-Vector Race & Atomicity Analysis  
**Scope:** Automated Retention Workers, Legal Hold Management, Data Scrubbing Pipeline, DSAR Exports  

---

## 1. Threat Matrix (36 Attack Vectors)

| ID | Threat Vector | Attack Scenario | Impact | Mitigation | Detection Mechanism | Automated Test |
| :- | :--- | :--- | :--- | :--- | :--- | :--- |
| **T01** | **Authentication Bypass** | Unauthenticated actor calls `/admin/retention/purge/execute/`. | Data destruction without credentials. | `IsAuthenticated` enforced globally. | 401 Unauthorized log. | `test_unauthenticated_cannot_execute_purge` |
| **T02** | **Privilege Escalation** | Student tokens invoke `/admin/legal-holds/` or `/admin/retention/purge/`. | Student freezes evidence or scrubs records. | `IsAdmin` permission class strictly enforced. | 403 Forbidden audit log. | `test_student_cannot_place_legal_hold` |
| **T03** | **IDOR on Student Export** | Student A requests export of Student B's `attempt_id`. | Unauthorized access to another student's exam responses & photos. | Verify `attempt.student == request.user` before queueing job. | Security alert on mismatched user/attempt. | `test_dsar_cross_student_protection` |
| **T04** | **Premature Purge Race** | Retention worker sweeps an attempt that is in-flight or awaiting result finalization. | Permanent loss of exam submissions before grading. | `RetentionService.is_eligible_for_purge()` requires terminal status, finalized result, and historical summary. | Worker skips ineligible attempts and logs warning. | `test_in_progress_attempt_never_purged` |
| **T05** | **Legal Hold ↔ Purge Race (Attempt)** | Admin creates attempt hold concurrently while purge worker is locking attempt. | Spoliation of evidence during disciplinary inquiry. | Both operations lock `TestAttempt` inside `transaction.atomic()`; worker checks active holds under lock. | Purge run marks attempt `SKIPPED_LEGAL_HOLD`. | `test_legal_hold_vs_purge_race` |
| **T06** | **Legal Hold ↔ Purge Race (Student)** | Admin places student-level hold while worker is processing one of their attempts. | Destruction of evidence of student under investigation. | Worker locks `User` row and queries `LegalHold` where `scope='STUDENT'`. | Immediate purge deferral. | `test_student_hold_vs_purge_race` |
| **T07** | **Legal Hold ↔ Purge Race (Assessment)** | Admin places assessment-level hold while worker processes attempt. | Destruction of cohort evidence under institutional audit. | Worker locks `Assessment` row and queries `LegalHold` where `scope='ASSESSMENT'`. | Immediate purge deferral. | `test_assessment_hold_vs_purge_race` |
| **T08** | **Filesystem Failure After DB Scrub** | Database scrub commits, but OS unlink of keyframe JPEGs fails. | Inconsistent state; orphaned biometric files left on disk. | Filesystem cleanup decoupled into `FileCleanupQueue`; worker retries unlinking idempotently. | `FileCleanupQueue.status = 'RETRYING'` logged. | `test_filesystem_failure_after_db_commit` |
| **T09** | **Partial Filesystem Cleanup** | 10 keyframe files exist; 6 delete successfully, 4 fail. | Misleading compliance report claiming full destruction. | System records exact deleted count (6) and queues 4 in `FileCleanupQueue`. Tombstone is NOT minted until 10/10 confirmed. | Status alert on incomplete unlinks. | `test_partial_filesystem_cleanup` |
| **T10** | **Tombstone Forgery / Tampering** | Attacker tampers with `RetentionTombstone` to fake destruction or hide data. | Fraudulent compliance claim. | Keyed HMAC-SHA256 integrity proof. Model `save()` and `delete()` raise `PermissionDenied`. | Signature verification failure. | `test_tombstone_hmac_sha256_proof_computation` |
| **T11** | **Tombstone Deletion Attack** | Malicious admin attempts to delete a tombstone via API or script. | Destruction of audit proof. | Model `delete()` raises `PermissionDenied`; no delete view exists. | Database denial. | `test_tombstone_immutability_save_and_delete_blocked` |
| **T12** | **Duplicate Tombstone Minting** | Concurrent purge tasks attempt to generate duplicate tombstones for same attempt. | Broken audit trail. | `RetentionTombstone.attempt_id` has database `UNIQUE` constraint. Service checks existing tombstone before minting. | DB IntegrityError handled idempotently. | `test_duplicate_tombstone_prevention` |
| **T13** | **Path Traversal in File Cleanup** | Malicious path in `ProctoringEvidence` attempts to unlink host system files. | Host file deletion. | Filesystem cleanup strictly validates `os.path.abspath(file_path).startswith(MEDIA_ROOT/evidence/)`. | Path traversal raises `SuspiciousFileOperation`. | `test_path_traversal_on_evidence_cleanup_blocked` |
| **T14** | **Path Traversal on DSAR Download** | Manipulated export URL attempts to download files outside `media/exports/`. | Host file disclosure. | Download view validates file path strictly within `MEDIA_ROOT/exports/`. | File access bounds check. | `test_path_traversal_on_dsar_export_download_blocked` |
| **T15** | **DSAR Hidden Test Case Leakage** | Student requests DSAR export hoping to extract hidden evaluation test cases. | Leaked answer keys and evaluation secrets. | Strict allowlist filter redacts hidden test inputs, outputs, and compiler args. | Automated payload inspection. | `test_dsar_hidden_test_protection` |
| **T16** | **DSAR Cross-Student Leakage** | Group assessment export leaks other students' responses in the same room. | Peer privacy violation. | Export query filters strictly by `attempt.student == request.user`. | Zero cross-student data check. | `test_dsar_cross_student_protection` |
| **T17** | **DSAR ↔ Purge Race** | Purge worker runs while DSAR export is actively reading attempt telemetry. | Incomplete, corrupted archive containing half-deleted data. | Shared read boundary locks attempt; purge worker checks for in-flight DSAR jobs and defers. | Export completes cleanly before purge. | `test_dsar_vs_purge_race` |
| **T18** | **DSAR Post-Purge Crash** | Student requests DSAR after 30-day purge has already executed. | 500 error or attempt to read nonexistent rows. | Endpoint returns `AVAILABLE_PARTIAL_ARCHIVE` containing permanent transcript & tombstone. | Deterministic partial state returned. | `test_dsar_after_detailed_purge` |
| **T19** | **Manual Purge Stale Preview Abuse** | Admin generates preview, holds are placed, and admin later executes with stale preview. | Destruction of newly held records. | Execution requires `preview_token` and re-evaluates all eligibility and hold criteria under row lock. | Token expiry (300s) or eligibility rejection. | `test_manual_purge_stale_preview_rejected` |
| **T20** | **Denial of Service via Heavy Purge** | Triggering purge of 100,000 attempts at once locks database tables during live exam. | Database deadlock; student autosaves timeout. | Chunking with `CHUNK_SIZE = 100`, `select_for_update(skip_locked=True)`, and inter-batch yields. | Celery task execution time monitoring. | `test_celery_beat_purge_batch_task` |
| **T21** | **Celery Duplicate Delivery Race** | Celery delivers the same purge task twice simultaneously to two worker threads. | Race condition, double-deletion, duplicate tombstones. | Atomic transaction with attempt row-lock and check on `attempt.answers.exists()`. | Idempotent check returns cleanly if already purged. | `test_filesystem_cleanup_retry_idempotency` |
| **T22** | **DSAR Export Flooding (DoS)** | Student repeatedly triggers export jobs to fill disk storage. | Storage exhaustion via ZIP generation. | Rate limiting (max 3 export requests per student per day) + 7-day TTL auto-cleanup. | Rate limit throttle (HTTP 429). | `test_student_dsar_export_job_generation` |
| **T23** | **Sensitive Data in Audit Logs** | Scrubbed code or answers logged in audit log parameters. | Telemetry persists inside audit log tables defeating retention. | Audit logging records only record counts, bytes reclaimed, and IDs; never raw answer text. | Automated log sanitizer. | `test_legal_hold_placement_and_release_workflow` |
| **T24** | **Replay Attacks on Legal Hold Release** | Intercepted hold release token replayed to unfreeze held evidence prematurely. | Unauthorized evidence destruction. | Hold release requires authenticated admin session with explicit CSRF token & state validation. | Invalid state transition rejected (`RELEASED` -> `RELEASED`). | `test_legal_hold_placement_and_release_workflow` |
| **T25** | **SQL Injection via Search Filters** | Attacker injects SQL into `/admin/tombstones/?search=` or `/admin/legal-holds/?search=`. | Database compromise. | Django ORM parameterized queries with strictly whitelisted search fields. | SQL parser / security scan. | `test_admin_retention_metrics_calculation` |
| **T26** | **XSS in Legal Hold Justification** | Admin enters malicious `<script>` in legal hold title or reason. | Stored XSS attacking other administrators. | HTML sanitization on text inputs; React automatic escaping on frontend. | CSP + output escaping verification. | `test_legal_hold_scope_validation` |
| **T27** | **Grade / Score Modification Exploit** | Purge worker inadvertently alters `total_score_earned` on `AssessmentResult`. | Academic transcript corruption. | `AssessmentResult` scores are immutable; purge worker only modifies `details_purged = True`. | Immutability check raises `PermissionDenied` on score change. | `test_purge_worker_never_modifies_official_scores` |
| **T28** | **Active Assessment Interference** | Purge worker selects an active or paused test attempt and corrupts live answers. | Exam interruption. | Query filters strictly require `status IN [SUBMITTED, EXPIRED, CANCELLED]`. | Inactive attempts rejected. | `test_in_progress_attempt_never_purged` |
| **T29** | **Lock-Order Violation / Deadlock** | Purge worker locks Attempt then Assessment while Hold creator locks Assessment then Attempt. | Transaction deadlock, 500 errors, aborted operations. | Global lock hierarchy (`Assessment -> User -> Attempt -> RetentionRecord -> LegalHold`) enforced. | Deadlock detector exception monitoring. | `test_global_lock_order_deadlock_prevention` |
| **T30** | **DSAR Snapshot vs Purge Race** | Purge begins while export transitions between `SNAPSHOT_PENDING` and `SNAPSHOT_ACQUIRED`. | Data scrubbed during payload copy. | Snapshot acquisition locks `TestAttempt` and `RetentionRecord` before materializing data. | Snapshot protection status check in purge worker. | `test_dsar_snapshot_acquisition_vs_purge_race` |
| **T31** | **DSAR State Manipulation** | Attacker forces `ExportJob.status = READY` via manipulated API request. | Unauthorized access to incomplete or unencrypted archive. | ExportJob states are server-authoritative and can only be transitioned by celery workers. | State transition validation. | `test_student_dsar_export_job_generation` |
| **T32** | **Key Rotation & Old Key Exposure** | Encryption key rotated while student has an unexpired encrypted archive. | Student unable to decrypt archive, or old keys leaked. | `encryption_key_version` tagged on `ExportJob`; master keys injected via vault; old keys preserved for 7-day archive TTL. | Key version resolution check. | `test_dsar_aes_256_gcm_encryption_and_key_versioning` |
| **T33** | **Export Archive Theft At-Rest** | Attacker breaches filesystem and accesses raw `.zip` export archives. | Bulk student telemetry disclosure. | Archives encrypted at rest with `AES-256-GCM` using unique 96-bit nonces. | Decryption without key yields authentication failure. | `test_dsar_aes_256_gcm_encryption_and_key_versioning` |
| **T34** | **Permanent EUID Exposure** | Excessive student identity leaked via permanent audit tombstones. | Unnecessary PII exposure. | Roll numbers excluded; EUID retained strictly pursuant to institutional accreditation audit justification. | Data minimization unit check. | `test_tombstone_data_minimization` |
| **T35** | **Tombstone IDOR / Unauthorized Access** | Student or unauthorized instructor accesses `/admin/tombstones/`. | Leakage of compliance metadata and attempt identifiers. | `RetentionTombstone` is classified as `INTERNAL AUDIT DATA (RESTRICTED)`; admin-only object authorization. | 403 Forbidden check. | `test_student_cannot_access_admin_retention_endpoints` |
| **T36** | **Filesystem Deletion Under DB Lock** | Purge worker performs blocking `os.remove` loops while holding database row locks. | Severe connection pool exhaustion and transaction timeouts. | No-I/O-under-lock rule: DB scrub commits first; file unlinking queued in `FileCleanupQueue` for async Celery task. | Transaction execution time monitoring. | `test_decoupled_file_cleanup_queue` |
| **T37** | **ExportJob Lock-Order Inversion** | Transaction locks `ExportJob` then `TestAttempt` or `RetentionRecord`. | Deadlock hazard under high concurrent export/purge volume. | Global lock order enforced: `Scope Owner -> Attempt -> RetentionRecord -> ExportJob`. `ExportJob` acquired last. | Deadlock detector exception monitoring. | `test_export_job_lock_order_compliance` |
| **T38** | **Snapshot Rollback False Protection** | Snapshot acquisition transaction fails/rolls back but leaves job in a state that blocks purge. | Permanent denial of retention purge; unpurged telemetry persists indefinitely. | No false protection invariant: transaction rollback leaves status `SNAPSHOT_PENDING` which Celery catches and marks `FAILED`. | Orphaned protected state monitor. | `test_dsar_snapshot_acquisition_rollback` |
| **T39** | **Key-Version Mismatch on Download** | Master key rotates and student downloads unexpired archive encrypted with older key version. | Decryption failure; student denied legitimate DSAR access. | Key retention invariant: old key versions remain active in secret manager until 100% of archives tagged with that version expire. | Key version lookup verification. | `test_key_rotation_while_old_archive_valid` |
| **T40** | **Premature Key Retirement** | Administrator retires key version before dependent 7-day archive TTL expires. | Unrecoverable archive decryption error. | Service checks `ExportJob.objects.filter(encryption_key_version=v, expires_at__gt=now())` before retiring keys. | Key retirement guard check. | `test_old_key_unavailable_fails_safely` |
| **T42** | **Expired Archive Key Over-Retention** | Retaining retired master key versions indefinitely long after archives expire. | Expanded attack surface for cryptographic material. | Key retirement policy: once all dependent archives expire and are unlinked, the old key version is permanently decommissioned. | Secret inventory audit. | `test_expired_archive_no_longer_requires_old_key` |
| **T43** | **Stale DSAR Job Blocking Retention** | Worker crashes during `SNAPSHOT_PENDING`, indefinitely blocking purge sweeps. | Telemetry persists indefinitely; violates 30-day retention mandate. | Bounded lease (`DSAR_SNAPSHOT_PENDING_TIMEOUT = 15m`); purge ignores jobs with expired leases; recovery marks them `FAILED`. | Stale pending lease monitor. | `test_stale_snapshot_pending_recovery` |
| **T44** | **False Stale Detection** | Recovery worker marks active worker's job `FAILED` due to uncoordinated check. | Valid student export aborted prematurely. | No false failure invariant: recovery acquires `TestAttempt + RetentionRecord` serialization locks and re-verifies lease under lock. | Active worker heartbeat check. | `test_stale_recovery_vs_snapshot_acquisition_race` |
| **T45** | **DSAR Stale Recovery vs Purge Race** | Recovery worker marks job failed while purge worker evaluates attempt. | Concurrency conflict or uncoordinated scrub decision. | Both recovery and purge synchronize through the exact same `TestAttempt + RetentionRecord` serialization locks. | Shared transaction boundary log. | `test_stale_recovery_vs_purge_race` |
| **T46** | **ExportJob-Only Concurrency Guard** | Implementation checks `ExportJob` state without locking `TestAttempt + RetentionRecord`. | Subordinate state race; purge destroys source data while DSAR is reading. | Authoritative serialization invariant: `ExportJob` is subordinate; all checks require `TestAttempt + RetentionRecord` row locks. | Code linting and transaction check. | `test_export_job_lock_order_compliance` |
| **T47** | **Lease Manipulation via API** | Attacker injects payload to extend `lease_expires_at` to delay evidence purge. | Unauthorized purge postponement. | `lease_expires_at` and `heartbeat_at` are non-editable server-authoritative fields managed exclusively by background workers. | Serializer field validator. | `test_student_cannot_access_admin_retention_endpoints` |
| **T48** | **Heartbeat Spoofing / Infinite Extension**| Faulty worker repeatedly bumps heartbeat beyond reasonable bounds to prevent purge. | Permanent purge block. | Hard ceiling enforced: total elapsed time from `started_at` cannot exceed 60 minutes regardless of heartbeats. | Hard ceiling lease validator. | `test_stale_snapshot_pending_recovery` |
